# Socioeconomic Patterning of Obesity Among Non-Pregnant Women in Ghana

## Overview

This repository contains the R scripts used for the study:

**Socioeconomic Patterning of Obesity Among Non-Pregnant Women in Ghana: Evidence from the 2022 Ghana Demographic and Health Survey**

Author: **Mathias Kwame Ahianou**  
Affiliation: **Independent Researcher, Ghana**

The analysis is a cross-sectional secondary analysis of the 2022 Ghana Demographic and Health Survey (GDHS). It estimates obesity prevalence among non-pregnant women aged 15–49 years and examines associations with age, place of residence, educational attainment, and household wealth.

## Data availability and DHS restrictions

The DHS microdata are **not included in this repository**. Users must register with The DHS Program, request access to the 2022 Ghana DHS, and comply with the applicable DHS data-use conditions.

After obtaining authorised access, place the Women's Individual Recode Stata file in:

`data_raw/GHIR8CFL.DTA`

The analysis scripts expect that exact relative path and filename.

Do not commit or redistribute the DHS microdata through this repository.

## Analysis workflow

1. `00_packages.R` loads the required R packages.
2. `01_load_and_clean.R` imports the DHS Individual Recode file, derives BMI and obesity variables, recodes the explanatory variables, creates the DHS sampling weight, and restricts the working dataset to non-pregnant women.
3. `02_descriptive_analysis.R` performs exploratory **unweighted** descriptive checks. These crude calculations are retained to document the analysis workflow but are **not the source of the manuscript's survey-weighted prevalence estimates**.
4. `03_survey_weighted_analysis.R` defines the complex survey design, estimates overall weighted obesity prevalence and BMI-category distribution, and fits the survey-weighted multivariable logistic regression model.
5. `04_tables_and_figures.R` produces Tables 1–3 and Figures 2–3.
6. `05_forest_plot.R` produces Figure 4 from the final survey-weighted regression model.
7. `99_run_project.R` sources the scripts in sequence and can be used to run the full workflow.

## Main variable definitions

- BMI: DHS variable `v445 / 100` after treating DHS special values as missing.
- Obesity: BMI ≥ 30 kg/m².
- Pregnancy status: `v213`; pregnant women are excluded from the analytical population.
- Age: `v012`.
- Place of residence: `v025` (urban/rural).
- Educational attainment: `v106` (no education, primary, secondary, higher).
- Household wealth quintile: `v190` (poorest to richest).
- Sampling weight: `v005 / 1,000,000`.
- Primary sampling unit: `v021`.
- Stratum: `v023`.

The final survey-weighted logistic regression model is:

`obesity ~ age + residence + education + wealth`

## Running the analysis

Open R with the repository root as the working directory. Confirm that the authorised DHS file is available at `data_raw/GHIR8CFL.DTA`, then run:

```r
source("99_run_project.R")
```

The scripts use relative paths, so no user-specific local drive path is required.

## Required R packages

The supplied workflow uses the following packages:

- haven
- tidyverse
- janitor
- survey
- gtsummary
- broom
- skimr
- flextable
- officer

`ggplot2` is loaded through tidyverse and is also called explicitly in the figure scripts.

Package versions are not pinned in the supplied analysis files. For exact long-term computational reproducibility, a future archived release may additionally record `sessionInfo()` or use a dependency lockfile.

## Outputs

When the relevant scripts are run, publication outputs are written to `outputs/tables/` and `outputs/figures/`. These include the survey-weighted descriptive tables, regression table, prevalence figures, and adjusted-odds-ratio forest plot.

Figure 1 (analytical-sample flow diagram) is not generated by the supplied R scripts and should therefore be treated as a manuscript figure rather than a programmatically reproduced output of this repository.

## Reproducibility note

This repository provides analysis code only. Reproduction of numerical results requires authorised access to the same 2022 Ghana DHS Individual Recode dataset and a compatible R environment. The DHS microdata remain subject to The DHS Program's access and data-use conditions.
